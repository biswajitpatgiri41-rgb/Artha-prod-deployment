# Verified source routes and collection notes

## Project scope extracted from `Final_work_flow.pdf`

The project forecasts India’s **monthly CPI Combined, General Group year-on-year inflation**. It treats seasonal-naive as an honesty benchmark, uses rolling-origin backtests, and requires point-in-time release/vintage awareness. Its MVP predictors are CPI/food, oil, INR/USD, RBI repo, and IIP. The wider model feature set also names WPI, GDP/GVA, credit, M3, U.S. CPI and policy rate, rainfall, global rates, commodity indices, bond yields, financial conditions, PMI where licensed, and consumption proxies. Seasonality terms, CPI lags, YoY changes, real repo, and multi-horizon target columns are **derived features**, not source datasets. CPI index bases (2012 and 2024) must not be silently concatenated.

## Official and fallback sources

- **MoSPI / NSO CPI:** e-Sankhyiki catalogue `https://esankhyiki.mospi.gov.in/catalogue-main/catalogue?product=CPI`; API base years `https://api.mospi.gov.in/api/cpi/getCpiBaseYear`; filter API `https://api.mospi.gov.in/api/cpi/getCpiFilterByLevelAndBaseYear`; paged observations `https://api.mospi.gov.in/api/cpi/getCPIData`. The public API supports base year, hierarchy level, series, state/sector/year/month numeric codes, and pagination; tested maximum page size is 100. The 2012 base has monthly historical observations; the 2024 base exposes current and back series plus detailed classification hierarchy. Current releases may be provisional. Preserve the base-year field and release/vintage.
- **RBI DBIE / Handbook:** `https://data.rbi.org.in/DBIE/`; Handbook index `https://rbi.org.in/Scripts/AnnualPublications.aspx?head=Handbook%20of%20Statistics%20on%20Indian%20Economy`. Relevant 2025–26 Handbook tables include 4 (GDP components), 34 (annual CPI), 36–38 (money stock/aggregates), 40 (repo/reverse-repo/SDF/MSF/CRR/SLR), 42–43 (bank credit), and 163 (monthly CPI). Current download files are linked on the RBI page. The file host presents a human-verification CAPTCHA and direct sandbox retrieval is blocked. RBI notes DBIE/SDMX Data Query as the near-real-time route. RBI sources are documented; where raw files are blocked, package accessible substitutes and label them clearly.
- **MoSPI IIP:** official product page `https://www.mospi.gov.in/themes/product/54-index-of-industrial-production`; e-Sankhyiki catalogue `https://esankhyiki.mospi.gov.in/catalogue-main/catalogue?product=IIP`. Base periods include 2022–23, 2011–12, 2004–05 and 1993–94; the latest official base transition is 2022–23 in 2026. A free long-history substitute is OECD via FRED series `INDPROINDMISMEI`, monthly, seasonally adjusted, 2015=100, April 1994–January 2023, with OECD provenance. It is stale at its observed end date and not a replacement for current MoSPI vintages.
- **WPI:** Office of the Economic Adviser (OEA), `https://eaindustry.nic.in/download_data_1112.asp`; official monthly file `https://eaindustry.nic.in/indx_download_1112/monthly_index_202606.xls`, from April 2012 onward, 2011–12 base; calendar-year and fiscal-year averages are linked on the same page. The latest two monthly values are provisional. OEA also offers older/newer-base series; do not splice different bases without an official bridge.
- **EIA oil:** official daily WTI workbook `https://www.eia.gov/dnav/pet/hist_xls/RWTCd.xls` and Brent workbook `https://www.eia.gov/dnav/pet/hist_xls/RBRTEd.xls`; monthly averages use the API series `RWTC` and `RBRTE` or corresponding official pages. API v2 requires a free EIA key; the XLS routes are key-free. WTI begins 1986 and Brent 1987, USD/barrel. Monthly averages are unweighted averages of business-day closes.
- **FRED / U.S. context:** direct graph CSV endpoint `https://fred.stlouisfed.org/graph/fredgraph.csv?id=...`; key series: `CPIAUCSL` (U.S. CPI), `CPILFESL` (core CPI), `FEDFUNDS` (monthly effective federal funds rate), `DFF` (daily rate), `UNRATE`, `DGS10`, `DGS2`, `DEXINUS` (INR per USD), `DCOILWTICO`, `DCOILBRENTEU`, `DTWEXBGS`, `M2SL`. FRED API requests require a key; the graph CSV route was accessible. Cite source series and retain retrieval date; some underlying series have separate rights. India CPI fallback `INDCPALTT01IXNBM` is monthly OECD/FRED, but it is stale and not the current MoSPI 2024-base series.
- **IMF:** IMF API resource page `https://data.imf.org/en/Resource-Pages/IMF-API`; CPI dataset `https://data.imf.org/en/datasets/IMF.STA:CPI`; WEO `https://data.imf.org/en/datasets/IMF.RES:WEO`. The official pages describe the CPI dataset and SDMX 2.1/3.0 access, but no raw IMF monthly CPI extract is included in this ZIP; the legacy `dataservices.imf.org` endpoint failed DNS during final retrieval. OECD monthly India CPI index and YoY files are included as related alternatives, not as identical IMF or MoSPI release vintages. The April 2026 WEO all-country workbook route observed in source verification: `https://data.imf.org/-/media/iData/External-Storage/Documents/2F78EE59F79143A7921E5E203D3AAA80/en/WEOApr2026all.xlsx`. Retain dataset name/vintage and IMF attribution; public retrieval is not a blanket redistribution license.
- **World Bank:** WDI API `https://api.worldbank.org/v2/country/{country}/indicator/{code}?date=1960:2025&format=json&per_page=20000`; no API key needed. WDI is annual and includes all countries/aggregates. Relevant codes include inflation `FP.CPI.TOTL.ZG`, CPI index `FP.CPI.TOTL`, GDP growth `NY.GDP.MKTP.KD.ZG`, INR/USD `PA.NUS.FCRF`, imports `NE.IMP.GNFS.ZS`, private credit `FS.AST.PRVT.GD.ZS`, broad money `FM.LBL.BMNY.GD.ZS`, and real interest `FR.INR.RINR`. The API is CC BY 4.0; cite World Bank and underlying source.
- **World Bank Pink Sheet commodities:** monthly historic workbook `https://thedocs.worldbank.org/en/doc/74e8be41ceb20fa0da750cda2f6b9e4e-0050012026/related/CMO-Historical-Data-Monthly.xlsx`. Includes Brent/WTI/Dubai, food, grain, vegetable-oil, fertilizer, energy, and non-energy series. These are global nominal-USD benchmark prices, not India landed/retail prices. File-level notices should be retained; the current PDF has an “Official Use Only” footer, while the data catalog marks the dataset public/CC BY 4.0.
- **OECD CPI panel:** verified monthly India route `https://sdmx.oecd.org/public/rest/data/OECD.SDD.TPS,DSD_PRICES@DF_PRICES_ALL,1.0/IND.M.N.CPI.PA._T.N.GY?startPeriod=1990-01&dimensionAtObservation=AllDimensions&format=csvfilewithlabels`; raw index uses `.../IND.M.N.CPI.IX._T.N._Z?...`. Monthly India headline YoY CPI is available from 1990 to the current publication window. API usage is free under OECD terms; rate limits apply. Use the dataflow and units in metadata.
- **IMD rainfall:** official free regional monthly/seasonal table `https://dsp.imdpune.gov.in/home_ogd_rainfall.php`; POST field `region1` with `WHI`, `NEI`, `NWI`, `PNI`, `CNI`. Each table supplies monthly, seasonal, and annual mm from 1901 through 2024 (124 years). Official 0.25-degree daily gridded NetCDF form `https://www.imdpune.gov.in/cmpg/Griddata/RF25.php` with POST `RF25=YYYY`; stated historical period 1901–2024. This package includes all 13 annual grid files for 2012–2024, not the full 1901–2024 grid; the regional summary contains 620 region-year records. Open fallbacks include CHIRPS v3 `https://data.chc.ucsb.edu/products/CHIRPS/v3.0/` and ERA5-Land, but they are not IMD observations.
- **PMI and consumption:** India PMI is S&P Global/HSBC licensed; no public bulk-history route was verified. Public release headlines can be cited, but do not reconstruct a licensed full series. Alternatives are NPCI monthly UPI volume/value from `https://www.npci.org.in/product/upi/product-statistics`, RBI Digital Payments Index (semiannual), and annual NSO PFCE. These are proxies, not direct consumer spending measures.
- **FRED/OECD India central-bank-rate proxy:** `IRSTCB01INM156N` (`https://fred.stlouisfed.org/series/IRSTCB01INM156N`) is monthly, percent, not seasonally adjusted, January 1968–December 2023 (672 observations), sourced from the OECD Main Economic Indicators through FRED. The last shown value is 6.75% in December 2023. It is a central-bank-rate series, not guaranteed to equal the RBI policy repo rate across every policy regime, and it has no 2024–26 observations. FRED’s series note calls for OECD attribution and warns of copyrighted data.
- **RBI DBIE landing snapshot:** `https://data.rbi.org.in/` showed repo 5.25%, reverse repo 3.35%, CRR 3.00%, SLR 18.00%, and SDF 5.00% when captured on 2026-10-08. The landing page excerpt does not state each rate’s effective date; this is a retrieval-date snapshot, not a historical rate series.
- **UPI mirror metadata:** Dataful page `https://dataful.in/datasets/432/` identifies an NPCI-sourced monthly volume/value/banks-live series with 124 rows, fiscal years 2016–17 to 2026–27, updated 2026-10-05. The page advertises CSV/XLSX/Parquet downloads, but its dataset download path is client-rendered/account-gated; no data file was retrieved in this run. UPI counts/values are activity proxies, not household consumption. The directly fetched NPCI page displayed only a small current-month window.
- **Global panel expansion:** To satisfy the request for more volume without adding unrelated data, collect broad cross-country WDI indicators and full all-country IMF WEO, global monthly commodity prices, multi-economy CPI where accessible, and India-specific source series at their available historical frequencies.

## Collection constraints

- The package should contain only actual retrieved observations and original source files. Any source that cannot be downloaded should be explicitly marked “not retrieved” with its official link and an accessible alternative, not represented by fabricated/simulated values.
- Maintain source, series code, frequency, unit, date range, source URL, retrieval date, base year, and known release/vintage caveats in the catalog.
- Historical CPI base 2012 and base 2024 must remain separate; 2024 back series is included as MoSPI-provided back data, not a casual splice.
