# Deterministic research workflow

`app.workflows.graph.run_workflow()` is the bounded async orchestration entry point used by `POST /research`. Its fixed sequence is planner → registered-series data retrieval → growth → external → inflation placeholder → econometrics → policy → critic → report. The graph is explicit and sequential rather than LangGraph because LangGraph is not a project dependency. Synchronous domain calls are offloaded to worker threads. Questions are limited to 2,000 characters, and the planner's series IDs are filtered against `SERIES_REGISTRY` with a maximum of 16 inputs.

The API assigns the run UUID and passes it into the graph so persisted events, the report, and the run aggregate share one identifier. Existing seasonal-naive forecast and backtest results, data-vintage metadata, and submitted scenario assumptions are attached to the econometrics context used by the critic and report. Scenario assumptions are not transformed into causal effects by this research workflow. When uploaded evidence is enabled, the API first retrieves and validates evidence through the evidence service, then passes only those authorized result records to the graph's critic and report. Document evidence remains distinct from macro-series observations.

Agent outputs are validated against Pydantic schemas. Node failures are isolated so later nodes can proceed; durable error records contain the node and exception type, not exception messages. Run events are normalized into the API response and persisted with the aggregate through `ResearchRepository`. Production requires Supabase and the reviewed migrations; development can use atomic local JSON replacement. `/research/{run_id}/stream` returns persisted events and is not a live streaming endpoint.

The graph and route integration are implemented, but not every analytical specialist is complete. The inflation node is explicitly a placeholder, and growth, external, policy, critic, and report agents remain deterministic/provisional implementations. The service does not establish causal effects, official RBI advice, vintage-perfect backtests, or production-grade policy recommendations. Uploaded documents provide narrative context only and cannot validate future forecast accuracy. These limitations are surfaced in report warnings and disclaimers.
